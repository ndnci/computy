# Computy brand identity

The logo was created with the built-in **imagegen** tool and added to the project. Icon variants were generated with `tauri icon` from the original transparent image.

- Project original : [`public/computy-logo.png`](../public/computy-logo.png).
- Interface icon : [`public/icon.png`](../public/icon.png).
- Distribution icons : [`src-tauri/icons/`](../src-tauri/icons/).

Generation prompt:

> Use case: logo-brand. Asset type: final premium desktop application logo icon for Computy, a serious modern PC hardware health diagnostic utility. Create a single beautifully resolved distinctive app mark: three substantial precisely crafted folded circuit-like ribbons form an open letter C around a small luminous square processing core, with subtle layered depth, beveled edges and harmonious geometry. The C should feel like an intelligent friendly protective orbit around hardware, not a generic shield, checkmark, monitor, or stock microchip pictogram. Sophisticated forest-green and jade body, restrained chartreuse/lime inner surfaces, very subtle premium material highlights; modern approachable engineering brand. Compact iconic silhouette remains legible at 32 pixels, yet rich intentional sculptural design at large size, elegant balanced negative space. Orthographic front/isometric hybrid with only modest depth. Single isolated centered logo mark with generous 12% transparent padding. Genuine transparent background, no white or colored backdrop, no ground, no drop shadow beyond the mark, no sheet of variants, no mockup, no extra objects, no typography or letters as text, no watermark. This is the final usable standalone mark for an app, not a brand presentation.

The diagonal README presentations are composed in HTML/CSS from real light/dark screenshots, then captured with Playwright. Application screens are not redrawn or regenerated with AI.
